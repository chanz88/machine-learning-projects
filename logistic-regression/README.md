# Logistic Regression
A Logistic Regression project to predict whether an individual's annual income exceeds $50K based on personal, educational, and demographic features

## Dataset used
This project uses the Adult Income dataset, which contains information about individuals such as age, workclass, education, marital status, occupation, relationship, race, gender, capital gain/loss, hours worked per week, and native country

The target variable is income, which indicates whether an individual earns <=50K or >50K per year

## What I Did
- Data cleaning
- Missing value imputation
- Checking outliers
- Categorical feature encoding (One-Hot Encoding)
- Feature scaling with RobustScaler
- Logistic Regression
- Model evaluation
