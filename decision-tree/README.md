# Regression Tree
A simple Regression Tree project to predict medical insurance charges based on personal and demographic features

## Dataset used
This project uses dataset that contains information about individuals such as age, sex, BMI, number of children, smoking status, region, and medical insurance charges

The target variable is 'charges', which represents the individual's medical insurance cost

## What I Did
- Data preprocessing
- Categorical feature encoding
- Train-test split
- Regression Tree
- Model evaluation (and comparing it with linear regression)
